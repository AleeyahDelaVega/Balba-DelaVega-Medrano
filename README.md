# EUCLIDEAN DISTANCE FORMULA

## Description
- This program helps you get the distance between two points in a cartesian coordinate plane. Just enter the values of x1, y1, x2, and y2, then you'll immediately get the distance.

## How to run the program?
1. Open the file.
2. Input the values of x1, y1, x2, and y2.
3. Press enter, then the output will immediately show up.

## Inputs needed:
- Value of x1
- Value of x2
- Value of y1
- Value of y2

## Sample Output
- Sample 1

Enter x1: 2

Enter y1: 4

Enter x2: 7

Enter y2: 6

The distance between the two points is: 5.39

- Sample 2

Enter x1: 3

Enter y1: 5

Enter x2: 9

Enter y2: 11

The distance between the two points is: 8.49
